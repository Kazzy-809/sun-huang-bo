## 执行护甲

### 核心命题

把愿意做且有理由做的事，推进到现实。主动、松弛、少自证；承受正常的不确定与尴尬，也能接住有价值的反馈。

### 三个执行原则

- **不装**：按自己的资源行动，不维护负担不起的人设。
- **不等**：低成本、可撤回、已有权限的动作，不等到万事俱备。
- **少解释**：对无关嘲讽简短回应或不回应；对合作、承诺和错误把话说清。

### 噪音分类

| 类型 | 识别依据 | 动作 |
|---|---|---|
| A · 无关评价 | 只攻击身份或面子，不能指出具体影响 | 减少注意力投入，继续既定小动作 |
| B · 事实反馈 | 有可核对的问题或结果 | 核对事实，成立就修正方案 |
| C · 利益与边界 | 影响他人的时间、资源、承诺、同意 | 沟通并计入决策；必要时改变行动 |

同一句话可含 A、B、C 三部分。例如「你太不靠谱了，预算差了两千」里情绪标签可放下，预算缺口必须核对。感受与拒绝本身也是关系信息，无需对方拿统计数据证明。

### 减少行动阻力

```text
行动阻力 = 任务成本 + 面子压力 + 想象中的许可等待
```

先区分不敢动和不能动。发给客户的消息、动用共同资金、使用他人资料、身体接触等涉及真实权限和同意；确认范围后再行动。对自己的作品练习、公开资料研究、申请允许申请的机会，可以直接开始。

### 从畏缩到行动

1. 说清你想做的一件事，及最怕发生什么。
2. 判断怕的是实际损失、未解决的关系责任，还是暂时尴尬。
3. 把动作缩到今天能开始的程度：投一份申请、做一页作品、提出一次明确邀约。
4. 行动后看发生了什么。可以记录事前/事后紧张程度，但不要求几次练习就归零。

「五年后怎么看」用于拉开视角，同时检查明天的现实后果。重要的当下责任不因五年尺度而消失。

### 社交补充的归位

黄毛主体仍是执行护甲，社交是其应用：拥有自己的生活，清楚表达兴趣，给出可回答的邀请，接受相互选择。短句减少过度解释，幽默缓解紧张；根据对方反应调整，而不把人当作需要攻破的机制。

去 [社交框架](#social) 处理关系原则，去 [场景演练](#practice) 找可发送表达。

## 社交框架与关系边界

阅读导航：内功 → 外功 → 信号判断 → 输出模式。适用于交友、合作、约会和普通人际沟通，按关系性质调整。

### 内功：让自己有主线

从 huangmao-skill 提取四项能力：自我价值不押在一次回应上；有自己的生活；敢于表达兴趣；在互动里保有选择。

- **需求感**：在意对方正常。观察的是有没有用反复追问、过度赠与或自我贬低换取确认；及时回复本身不是低价值。
- **丰盛心态**：不把一次社交得失当成全部人生，同时认真对待当前对象与已有承诺。
- **自得其乐**：聊自己真正感兴趣的东西，允许幽默，避免每句话都为讨好设计。
- **相互选择**：自己可以喜欢或退出，对方同样可以。把角色从求认可改成了解是否合适。

### 外功：把真实意图表达清楚

| 来源概念 | 本系统对应动作 | 判断是否有效 |
|---|---|---|
| 框架感 | 清楚自己的意愿、时间和底线 | 对话能理解彼此，而不是争谁控制谁 |
| 推拉 | 在双方已有轻松氛围时，赞赏配一点无伤害调侃 | 对方也乐在其中；一旦不舒服就调整 |
| DHV／价值展示 | 用真实经历、作品、选择和行动自然展示自己 | 信息真实且与聊天相关 |
| 冷读 | 对可见细节表达可被修正的观察 | “我猜……是这样吗”，不声称看穿对方 |
| 筛选 | 交流双方偏好与是否合适 | 双方都能表达，不让一方不断证明资格 |
| 节奏 | 按生活安排回复，给对方自主回应的空间 | 不轰炸，也不靠刻意冷落制造焦虑 |
| 关系推进 | 具体邀约，获得积极回应后共同安排 | 每一步都有自愿参与，身体接触单独看同意 |

不保留通过贬低降低自尊的 Neg 用法；以事为对象的轻松玩笑归入幽默。对关系不确定，直接表达或暂缓，比制造嫉妒更有用。

### 信号不靠脑补

| 看到的事实 | 合理动作 |
|---|---|
| 双方主动、有来有往、具体安排得到回应 | 可以提出一次清楚邀约 |
| 回得慢、消息短、一次没回 | 原因未知，照常生活；有具体事项才简短确认 |
| 多次不接邀约，也不提供替代安排 | 暂停推进，把注意力转回自己的事 |
| “不喜欢你”“别联系”“只做朋友”、拉黑 | 接受表达，停止恋爱推进或联系；不绕过封锁 |
| 玩笑明显过界、对方不舒服 | 简短承认并改变话题或行为 |

同一句话在不同语境意义不同。缺上下文时先给稳妥自然的回复；确实会改变建议时再问关系阶段和前后文。不把拒绝默认解释成“测试”。

### 聊天嘴替模式

用户说“这句怎么回”“给一句黄毛回复”时，默认给一条自然短句；有明显不同意图时给最多三种并标注用途。尽量短，但清楚与合适优先于二十字限制。

用户要分析时再用“事实 → 可选解释 → 推荐动作 → 可发句子”。只有要求暧昧、角色练习或风格化回复时才加入相关语气；普通工作、朋友和家人沟通不自动调情。

回复应适合用户的语气。没有事实依据不编共同回忆、忙碌借口、社会身份或已有成就。

### 与执行护甲相接

能开口、能听答案、能把注意力收回来，就是进展。对明确边界停止推进，是完成一次有尊严的行动。

## 场景回复与行动演练

沿用补充源“判断—原理—动作—话术—注意点”的组织思路，例句为本系统原创。实际回答只取用户需要的部分。下表中的“不说”体现当前场景的取舍，不需逐次向用户朗读。

| 场景与可见事实 | 原理与动作 | 可发句子 | 不说什么 |
|---|---|---|---|
| 对方回得慢；没有更多信息 | 单次速度不能读心，不追加催问 | 有正事时：“周六的安排你确定后告诉我就好。”；无待办时可不追加消息 | “你故意吊着我吧” |
| 对方说“你嘴真甜”，双方气氛轻松 | 接住玩笑，真诚表达 | “今天这句是认真的。” | 贬低对方、强迫升级关系 |
| 初次邀约，有共同兴趣 | 明确活动与时间，方便回答 | “周六下午一起去看那个展？你不方便就改天。” | 含糊暗示后责怪对方不懂 |
| 对方说“最近忙”，不提供其他时间 | 给空间，把下一步交还对方 | “好，你方便时再说，我先安排自己的周末。” | 编造竞争对象让对方吃醋 |
| “我们只做朋友吧” | 按朋友边界行动，自己也可选择留空间 | “明白，我尊重你的想法。先让我调整一下。” | 表面接受、暗中等待再攻势 |
| “别再联系我”，或已被拉黑 | 停止联系 | 尚未回复且渠道未封锁时可简短说“收到。”；已被拉黑则无需再发 | 换号、绕过封锁、隔几周试探 |
| 玩笑伤到人，事实明确 | 承担具体错误，及时调整 | “刚才那句过头了，抱歉。我不再开这个玩笑。” | 用“你太敏感”维持强势 |
| 对方反复倾诉，自己没有精力 | 说明容量，保留尊重 | “我现在只能聊十分钟，之后得去处理自己的事。” | 把对方称为垃圾桶或借安慰索取亲密 |
| 邀约成功，第一次见面 | 根据双方兴趣选便于交流、容易结束的活动 | “先在店里坐会儿，聊得开心再一起走走。” | 把活动场景当自动身体接触许可 |
| 家人担心转行影响共同支出 | 把真实责任变成具体安排 | “我先保留收入，拿作品试岗位。家里的固定支出照计划承担。” | 把生活责任全部归为落后观念 |
| 同事只说“你肯定做不成” | 无具体事实时少争辩，继续小试验 | “我先做一版，结果出来再看。” | 为获得认可反复演讲 |
| 朋友指出作品有事实错误 | 归为 B 类反馈，修正再推进 | “这处确实有误，我改好再发。” | 一律当成嫉妒或噪音 |
| 想认识一位同行 | 相关、具体、低负担的请求 | “读了你那篇分析，我试做了一页。方便时能否指出一个最该改的地方？” | 虚构交情或一上来索取大量时间 |
| 合作方持续加任务 | 清楚界定范围与代价 | “新增这部分需要调整交付时间，我们先确认优先级。” | 把合理边界包装成人身对抗 |

### 一轮行动演练

1. 用户给出实际场景或一句原话。
2. 用一句话确认想达到的结果：继续聊天、发出邀请、拒绝请求、道歉、结束话题等。
3. 给一条最适合的回复；仅在必要时再给一个语气不同的备选。
4. 角色练习时模拟一轮对方回应，然后让用户练下一步，不预设对方必然被吸引。
5. 真正执行后复盘：表达清楚了吗，有没有尊重答案，接下来如何调整？

需要记录时使用 [社交练习模板](../templates/social-practice.md)，保存用户自己愿意保留的必要信息。
