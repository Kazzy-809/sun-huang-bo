# 07 · 肌肉资产负债表

## 身体账户的用途

沿用主模型的财务隐喻：把力量、活动能力、心肺与恢复看作值得维护的长期能力。体脂不是道德评价，肌肉量也不等于身体全部价值。

| 账户 | 记录方式 | 用来改变什么 |
|---|---|---|
| 能力 | 相似条件下的动作表现、日常耐力 | 选择训练内容与难度 |
| 恢复 | 主观疲劳、睡眠、休息后变化 | 调整任务量和训练量 |
| 身体成分（可选） | 相同测量条件下的体重、体脂估计 | 观察趋势，不被单次测量牵着走 |
| 维护投入 | 活动时间、饮食可持续性、必要健康管理 | 找到能坚持的安排 |

## 可计算的部分

```text
脂肪质量 = 体重 × 体脂比例
去脂体重 = 体重 × (1 − 体脂比例)
在去脂体重不变的假设下：情景体重 = 去脂体重 / (1 − 目标体脂比例)
```

去脂体重包含肌肉、骨骼、器官和水分，不等于肌肉量。目标体脂由用户提供；模型不根据性别或外貌默认设目标。

例如，75 kg、体脂估计 29%，去脂体重为 53.25 kg。若仅做“去脂体重不变、体脂 20%”的算术情景，体重为约 66.56 kg。实际变化还受测量与身体成分变化影响，不能据此推出需要几周或某种训练保证达成。

```powershell
python scripts/sunxue.py body --weight 75 --fat 29 --target-fat 20
```

## 饮食与消耗估算

照片能辅助记录，份量、配料和油量不清时给区间或先补充信息。包装标识、实际称量和完整训练记录优先于视觉猜测。估算总消耗时避免重复把已经包含在基础代谢中的组织消耗再加一次。

日常恢复与训练表现同样重要。不能仅凭体重变化判断肌肉增减，也不把每一餐都判成成功或失败。

## 保留能用的信息

使用 [身体记录模板](../templates/health-data.md)。已有检查结果可记录日期、单位与专业解读，筛查频率依据个人情况；不为所有人预设大套检查项目。
