# 05 · 三体耦合模型

## 一个内核，两个驱动

```text
孙学：决定值得做什么 ──→ 黄毛：把决定变成行动
          ↑                         ↓
          └──── 真实反馈与版本更新 ────┘
薄肌：为整个循环提供身体能力和恢复空间
```

「方向判断 × 身体续航 × 持续执行」帮助找短板：方向是否明确、精力是否够用、行动能否持续。根据当前问题的具体表现，找到最影响进展的一项。

## 八种组合，保留主模型命名

1 表示当前问题所需的能力够用；0 表示有具体表现需要补强；未知则暂不套组合。名称用于描述一时的卡点，引用前说明依据；用户不喜欢标签就用普通语言。

| 孙学 | 薄肌 | 黄毛 | 原模型名称 | 本版动作 |
|---|---|---|---|---|
| 1 | 1 | 0 | 被舆论劝退者 | 保留方向，完成一个低成本公开动作或沟通 |
| 1 | 0 | 1 | 碳基服务器宕机 | 减少过载，调整作息和任务容量 |
| 0 | 1 | 1 | 健身房打工人 | 用现有执行力做机会比较与真实试验 |
| 1 | 0 | 0 | 观众席常客 | 降低启动量，同时处理疲惫和畏缩 |
| 0 | 1 | 0 | 镜子里的努力 | 确认自己的目标，做一个面向真实反馈的作品 |
| 0 | 0 | 1 | 纯莽夫 | 先减无效投入，补方向与恢复 |
| 0 | 0 | 0 | 增量遗民 | 从最影响今天生活的一件事重建循环 |
| 1 | 1 | 1 | 三体齐备／进入护甲压力测试期 | 保持有效循环，在下一阶段检验瓶颈 |

## 启动顺序

没有紧急事项、也没有成熟习惯时，可按主模型思路：先安排一个能持续的身体动作，孙学判断并行，再逐步练习黄毛行动。

实际问题决定优先级。明天截止的录用选择先分析选项；急需完成的沟通先写好表达；过载到无法工作时先处理恢复。训练不是学习、申请或社交的前置资格。

## 用户要量化时

让用户分别按下表自评 0、1、2；已有叙述能判断时引用行为，不代填未知。

| 项 | 0 · 明显卡住 | 1 · 初步运转 | 2 · 当前够用 |
|---|---|---|---|
| 孙学 | 说不清眼前要选什么 | 有方向，关键假设待查 | 有依据、备选和下一步验证 |
| 薄肌 | 疲惫或恢复持续妨碍目标 | 正在调整，尚不稳定 | 当前活动与恢复支持日常任务 |
| 黄毛 | 被尴尬、等待或反复解释卡住 | 做过小动作，仍会中断 | 能执行，也会依据反馈和边界调整 |

CLI 参数顺序为「孙、薄、黄」，与原主模型的诊断顺序一致。2 记为组合中的 1，0/1 记为待补；这是本技能的整理约定。不给这三个主观分数相乘后冠以真实成功率。

## 一个问题怎么串起来

用户想换城市工作，又担心家人反对。

- 孙学：比较岗位质量、收入支出、成长和照护安排，找现成机会。
- 薄肌：估计通勤、工作节奏和恢复是否能持续。
- 黄毛：区别外界面子评价与家人真实需要；带具体安排沟通，推进申请。

输出重点是应选哪条路、先做什么和何时改判。默认无须把三层都讲一遍。
