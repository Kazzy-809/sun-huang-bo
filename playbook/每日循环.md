# 每日循环

把一天压缩成一个可重复的闭环：选一件值得做的事，做出结果，按身体状态安排强度，带着反馈进入下一天。

## 开始时

看今天能用的时间与状态。选一个最重要动作，写清完成到哪一步算有结果。有截止时间先处理截止时间。

## 行动时

- **孙学**：对准关键未知或目标成果，减少无止境收集资料。
- **黄毛**：把需要的申请、表达或交付做出去，接住真实回应。
- **薄肌**：安排适合自己的活动和恢复，避免用疲惫堆时长。

## 结束时

用 [每日模板](../templates/daily.md) 记下今天做了什么、得到什么、下一步是什么。愿意只保留在聊天里也可以；长期使用再存入自己的目录。

## 每周

用 [周复盘](../templates/weekly-review.md) 看投入是否换来想要的结果。调整一项最影响循环的条件。有效时继续；有证据再改。

可用工具打印今日模板：

```powershell
python scripts/sunxue.py today
```

需要保存时指定个人文件路径。个人记录放在自己的工作目录，技能目录只保存方法与空白模板。
